# Findings and Conclusion

## Findings

- Decision Tree provided interpretable classification results.
- Increasing tree depth improved training accuracy but caused overfitting.
- Random Forest reduced overfitting through ensemble learning.
- Feature importance analysis identified significant predictors.
- Cross-validation confirmed model stability.

## Conclusion

Random Forest outperformed Decision Tree in terms of accuracy, robustness, and generalization capability. The project demonstrates the effectiveness of tree-based machine learning algorithms for healthcare prediction tasks.
