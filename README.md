# AIML Task 5 - Decision Trees and Random Forests

## Project Overview
This project implements Decision Tree and Random Forest classification algorithms to predict heart disease using machine learning techniques.

## Objectives
- Train a Decision Tree Classifier.
- Visualize the Decision Tree.
- Analyze overfitting using tree depth.
- Train a Random Forest Classifier.
- Compare model performance.
- Analyze feature importance.
- Evaluate models using cross-validation.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-Learn

## Dataset
Heart Disease Dataset

## Outputs
- Decision Tree Visualization
- Feature Importance Analysis
- Confusion Matrices
- Cross Validation Results
- Model Comparison
- Prediction Files

## Conclusion
Random Forest achieved better generalization and classification performance compared to a single Decision Tree.
