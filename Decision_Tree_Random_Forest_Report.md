# Decision Trees and Random Forests Report

## Objective
To build and compare Decision Tree and Random Forest models for Heart Disease Prediction.

## Dataset
Heart Disease Dataset containing medical attributes and target labels.

## Methodology
1. Data Loading
2. Data Preprocessing
3. Train-Test Split
4. Decision Tree Training
5. Tree Visualization
6. Overfitting Analysis
7. Random Forest Training
8. Feature Importance Analysis
9. Cross Validation
10. Model Comparison

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1 Score
- Cross Validation Accuracy

## Results
Random Forest demonstrated better predictive performance and reduced overfitting compared to Decision Tree.

## Conclusion
Ensemble learning through Random Forest improves classification accuracy and model robustness.
